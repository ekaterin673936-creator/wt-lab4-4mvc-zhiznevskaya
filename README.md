# WT-4 ASP.NET Core MVC — Автосалон

## Репозиторий

https://github.com/ekaterin673936-creator/wt-lab4-4mvc-zhiznevskaya

## Описание

Веб-приложение ASP.NET Core MVC для управления автопарком (прокат автомобилей).

**Функционал:**
- Список автомобилей (Bootstrap-каталог)
- Просмотр подробной информации
- Добавление нового автомобиля
- Редактирование
- Удаление

## Опубликованное приложение

URL появится после деплоя на Render
